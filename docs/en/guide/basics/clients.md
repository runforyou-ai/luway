## Download and install

## Connect to a server

The desktop and mobile apps connect using the full server address, including the `https://` or `http://` prefix. After detection succeeds, the confirmation area shows the target server's product name. Click **Connect** to open the login page. The bottom of the login page shows the current server's product name. Click **Change server** to return to the connection page. On desktop, hover over the product name in the connection confirmation area or login page to see the full address.

## Open in the app

The desktop workspace provides sidebar, back, and forward buttons at the top, including when the sidebar is collapsed. Drag the empty area at the top to move the window. macOS keeps its window controls on the left; Windows and Linux show minimize, maximize or restore, and close buttons on the right. Login and server connection windows have a fixed size.

Windows provides **File, Edit, View, and Window** menus in the title bar for closing windows, quitting, editing text, page zoom, and fullscreen. Press `F10` to focus the menu bar, or `Alt+F/E/V/W` to open a menu, then use the arrow keys, Enter, and Esc. Closing the main window hides it to the tray; **File → Quit** exits the app. macOS uses the system menu bar at the top of the screen.

## Updates and version compatibility

The web app updates together with the server and never needs a separate update. The desktop and mobile apps must match the server version:

- Each time the Windows or macOS desktop app connects to the server, it downloads the app version that matches the server. When the download finishes, it shows **Restart to update**, and the app restarts on the new version. The Linux desktop app, or an app whose folder your account can't write to, tells you a new version is available; click **Go to downloads** to install it from the download page.
- If the server no longer supports your app version after an update, the app shows an **Update required** page. The Windows and macOS desktop apps download the new version automatically; click **Restart to update** when it's ready. On the Linux desktop app, the mobile apps, or when your account can't write to the app's folder, click **Download new version** to open the server's download page, install the new version, and open the app again. You can also click **Change server** to connect to a different server.
- If the server is older than your app requires, the connection page says the server is out of date. Ask your administrator to update the server.
