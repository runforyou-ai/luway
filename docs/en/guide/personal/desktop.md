## Connect to a server

Under **Server address**, select `https://` or `http://`, then enter a domain name or IP address. Append a port number if your server uses a custom port. The default protocol is `https://`.

Pasting a complete URL selects its protocol automatically. Click **Detect** to check the server, then **Connect**. Your saved server address is filled in the next time you use the app.
