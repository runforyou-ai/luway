## Shared conversation files

Every conversation has a shared file area: direct chats, AI chats, group chats, and customer conversations. Members and AI employees in the conversation see the same files, and AI employees can read and write them whether or not they use a computer. In customer conversations, shared files stay inside the workspace and are not visible to the customer.

- Open the **Files** tab in the conversation side panel (on mobile, open **Files** from the conversation menu or the group details) to view, upload, download, and delete files. A file with the same name is never overwritten; the new file gets a number added to its name.
- Open the menu on a message attachment and choose **Save to conversation files** to copy it into the file area. Attachments are not added automatically.
- AI employees can list, read, create, and edit files in the file area, and can save attachments from the conversation into it. AI employees cannot delete files; only members can. AI employees can read PDF, Word, and similar documents but cannot edit them. When the AI employee's model can understand images, it can also view images in the file area.
- When the AI employee uses a computer, `shared/` in the conversation's folder on that computer is a copy of the file area, so commands and local agents can work with these files directly. See [Shared file copy](/docs/en/guide/ai-employees/computers/#shared-file-copy).
- Only the current version of each file is kept. After a member or AI employee changes a file, the list shows who changed it last and when.
