How to install, configure, upgrade, and maintain the {{product}} server.

Deployment administrators review scale and usage in [Platform overview](/docs/en/deployment/manage/overview/), manage access in [Accounts and workspaces](/docs/en/deployment/manage/accounts-workspaces/), and troubleshoot with [Status and diagnostics](/docs/en/deployment/manage/diagnostics/). Administration also covers [Branding](/docs/en/deployment/manage/branding/), [License](/docs/en/deployment/manage/license/), and [WeChat Open Platform](/docs/en/deployment/manage/wechat-open-platform/).

## Addresses

The server provides these entry points under the deployment address:

| Path | Content |
| --- | --- |
| `/` | Product home page, shown in Chinese or English based on the browser language |
| `/app/` | Web app, including first-time setup, sign-in, and workspace pages |
| `/docs/` | Product documentation for the current server version |
| `/en/download/` | Client download page, with the Chinese page at `/zh-cn/download/`. See [Client distribution](/docs/en/deployment/operate/client-distribution/) |
| `/clients/` | Client installer, update, and executor files |
