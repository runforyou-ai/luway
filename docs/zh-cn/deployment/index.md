部署与运维说明{{product}}服务端的安装、配置、升级与维护。

部署管理员在[平台概览](/docs/zh-cn/deployment/manage/overview/)查看规模与使用情况，在[账号与工作区](/docs/zh-cn/deployment/manage/accounts-workspaces/)管理访问，在[运行状态与诊断](/docs/zh-cn/deployment/manage/diagnostics/)排查问题。部署管理还包括[品牌](/docs/zh-cn/deployment/manage/branding/)、[授权](/docs/zh-cn/deployment/manage/license/)与[微信开放平台](/docs/zh-cn/deployment/manage/wechat-open-platform/)。

## 访问地址

服务端在部署地址下提供以下入口：

| 路径 | 内容 |
| --- | --- |
| `/` | 产品首页，按浏览器语言进入中文或英文页面 |
| `/app/` | Web 应用，首次安装、登录与工作区页面都在这里 |
| `/docs/` | 与当前服务器版本对应的产品文档 |
| `/zh-cn/download/` | 客户端下载页，英文页面在 `/en/download/`，见[客户端分发](/docs/zh-cn/deployment/operate/client-distribution/) |
| `/clients/` | 客户端安装包、更新包与执行器文件 |
