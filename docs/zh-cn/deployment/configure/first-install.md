创建平台管理员和第一个工作区。

## 初始化

首次安装在浏览器中完成。打开部署地址，进入登录入口，服务器尚未初始化时会显示初始化表单。

先确认部署地址，表单已用浏览器当前访问的地址预填，它是成员和客户访问本服务器使用的地址，之后可以在平台设置中修改，见[部署地址与名称](/docs/zh-cn/deployment/configure/address/)。服务器直接提供 HTTPS 且部署地址以 `https://` 开头时，提交后先为该域名自动签发证书，见[HTTPS 与反向代理](/docs/zh-cn/deployment/configure/https/#自动签发)。然后填写工作区名称、你的姓名、邮箱和密码并提交。工作区名称可以使用中文，在同一部署内不能重复，比较时忽略大小写。名称不能超过 32 个字符，保存时会去除首尾空白；密码至少需要 8 个字符。

完成后会自动登录并进入第一个工作区。工作区访问地址由服务器生成，在通用设置中可以查看和复制；修改工作区名称后，访问地址保持固定。

## 平台管理员

初始化创建的账号是平台管理员，同时加入第一个工作区。平台管理员可以管理平台账号、工作区以及注册和工作区创建策略。

## 注册与工作区创建

初始化后默认仅限受邀注册，工作区由平台管理员创建。平台管理员可以在「设置 → 平台 → 工作区与账号 → 注册与创建」中调整这两项策略，详见[账号与工作区](/docs/zh-cn/deployment/manage/accounts-workspaces/)。

桌面端和移动端连接已完成初始化的服务器后登录。
