创建平台管理员账号并进入平台管理后台。

## 初始化

首次安装在浏览器中完成。打开访问地址，进入登录入口，服务器尚未初始化时会显示初始化表单。

先确认访问地址，表单已用浏览器当前访问的地址预填，它是成员和客户访问本服务器使用的地址，之后可以在平台后台中修改，见[访问地址与名称](/docs/zh-cn/deployment/configure/address/)。服务器直接提供 HTTPS 且访问地址以 `https://` 开头时，提交后先为该域名自动签发证书，见[HTTPS 与反向代理](/docs/zh-cn/deployment/configure/https/#自动签发)。然后填写默认工作区名称、你的姓名、邮箱和密码并提交。密码至少需要 8 个字符。

完成后会创建默认工作区、建立平台后台会话并进入平台管理后台。管理员属于该默认工作区。

## 平台管理员

初始化创建的账号是平台管理员。平台管理员登录平台后台，可以管理平台账号、工作区以及注册策略与自建工作区额度，并可以支援进入任意工作区。

## 注册与自建额度

初始化后默认仅限受邀注册，自建工作区额度为 0。平台管理员可以在「平台后台 → 系统设置 → 站点设置」中调整注册方式，并在激活授权后调整自建额度，详见[账号与工作区](/docs/zh-cn/deployment/manage/accounts-workspaces/)。

桌面端和移动端连接已完成初始化的服务器后登录用户端。平台后台请在浏览器打开 Web 应用中的管理入口。
