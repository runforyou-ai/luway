设置成员和客户访问部署使用的地址、客户端连接时显示的部署名称，以及平台时区。

## 部署地址

部署地址是各端连接和 Web 访问使用的地址，例如 `https://support.example.com`，不带路径。服务器生成的邀请链接、网站访客的回访链接、渠道接入地址、文件地址等都以它开头。

首次安装时，表单用浏览器当前访问的地址预填部署地址，确认无误后提交即可，见[首次安装](/docs/zh-cn/deployment/configure/first-install/)。之后平台管理员可以在「设置 → 平台 → 部署配置 → 地址与 HTTPS」修改，所有服务器在 10 秒内使用新地址。已经发出的链接仍指向旧地址。

部署地址以 `https://` 开头时使用 HTTPS。服务器直接提供 HTTPS 时，同一页签设置证书来源：自动签发或上传证书，见[HTTPS 与反向代理](/docs/zh-cn/deployment/configure/https/)。

## 部署名称

部署名称显示在桌面端和移动端的服务器连接页，帮助成员确认连对了部署，不超过 64 个字符。留空时显示部署地址。

## 平台时区

平台时区决定运营数据按哪一天统计，首次安装时取平台管理员的时区。平台管理员在「设置 → 平台 → 部署配置 → 基本信息」修改，保存后按新时区重新统计全部历史运营数据，完成前「概览」显示「正在按新时区重新统计」。统计口径见[平台概览](/docs/zh-cn/deployment/manage/overview/#统计口径)。

「基本信息」中还有「上报运行指标与错误」开关，见[上报配置](/docs/zh-cn/deployment/manage/diagnostics/#上报配置)。
