替换产品名称、图标与客户端品牌。

## 部署品牌

平台管理员可以在「设置 → 平台 → 部署配置 → 品牌」为整个部署设置：

- 各界面语言的产品名称，留空的语言沿用构建品牌。
- 网站嵌入脚本在宿主页注册的全局对象名，以字母开头，只含字母和数字。
- 替换 Web 端网站图标的 PNG 图片，不超过 512 KB。

保存后所有服务器在 10 秒内使用新品牌，已打开的页面刷新后更新。

## 构建品牌

安装包名称、应用标识、客户端图标等构建时确定的内容来自构建品牌，部署品牌不会改变它们。

## 授权要求

部署品牌只在授权授予自定义品牌且未到期时生效。授权未授予时也可以保存，授权授予后自动生效；授权到期后恢复构建品牌，见[授权](/docs/zh-cn/deployment/operate/license/)。
