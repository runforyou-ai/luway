---
title: 文件存储
order: 5
---

选择本地目录或 S3 兼容对象存储保存文件。

文件存储由整个部署共用，平台管理员在「设置 → 平台 → 部署配置 → 文件存储」修改，所有服务器在 10 秒内生效。

## 本地存储

未开启对象存储时，新文件保存在服务器数据目录下的 `files`，数据目录可用 `data.directory` 指定，见[配置参考](/docs/zh-cn/deployment/configure/configuration/#数据目录)。文件经服务器下载，部署只能运行一台服务器。

## 对象存储

开启对象存储后，客户端经服务器签发的预签名请求把新文件直接上传到存储桶，读取时直接访问存储桶，服务器不转发文件内容。需要填写：

| 字段 | 说明 |
| --- | --- |
| 接口地址 | 服务器访问对象存储接口的地址 |
| 公开访问地址 | 成员和客户的设备读取文件使用的地址，可以是存储桶地址或 CDN 地址 |
| 区域、存储桶 | 存储桶所在区域与名称 |
| 访问密钥 ID、访问密钥 | 可以读写该存储桶的凭据 |
| 路径形式访问 | 以「接口地址/存储桶」的形式访问，MinIO 等自建服务通常需要开启 |

保存时服务器先用填写的凭据访问一次存储桶，无法访问时不保存。整个部署共用一个存储桶，对象键按工作区隔离。

## 存储桶跨域设置

浏览器和桌面端直接向存储桶上传、读取文件，存储桶需要允许来自部署地址的跨域 `PUT` 与 `GET` 请求。

## 切换存储方式

切换只影响新文件，已有文件按各自保存时的位置读取。关闭对象存储后，之前上传到存储桶的文件仍从存储桶读取，因此需要保留存储桶和凭据。

部署中有多台服务器运行时，对象存储不能关闭，见[多服务器运行](/docs/zh-cn/deployment/operate/multi-server/)。

## 临时文件清理

选择文件后立即上传为临时文件，保存业务数据时才正式使用。没有使用的临时文件 24 小时后过期，由服务端定时删除。
