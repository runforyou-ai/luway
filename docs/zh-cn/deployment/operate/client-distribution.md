## 下载入口

成员在下载页获取与服务器同版本的桌面端安装包。下载页位于部署地址的 `/zh-cn/download/`（英文为 `/en/download/`），产品首页和文档页头都有入口。Web 应用的「在客户端中使用」，以及客户端版本过低时的升级提示，也会打开这个页面。

服务器从客户端目录读取安装包与桌面端更新包，目录由配置项 `clients.directory` 或环境变量 `CLIENTS_DIRECTORY` 指定，默认为 `data/clients`。目录中的 `clients.json` 列出各平台的安装包和更新包及其大小和校验值，这些文件与它放在同一目录下，经 `/clients/<文件名>` 下载。

- 容器镜像内置同版本的桌面端安装包与更新包，客户端目录为 `/clients`，不需要额外配置。
- 使用二进制部署时，把 Release 中的 `clients.json` 和它列出的全部文件放进客户端目录。
- 服务端启动时读取客户端目录。`clients.json` 的版本与服务端版本不同，或目录中没有 `clients.json` 时，下载页显示当前服务器未提供安装包，桌面端也不会从这台服务器更新；列出的文件缺失、大小或校验值与记录不符，或更新包签名无效时，服务端无法启动。
- 移动端暂未提供下载，下载页显示即将推出。

## 桌面端更新

Windows 和 macOS 桌面端从所连接的服务器更新，客户端版本始终跟随服务器版本。升级服务器并更新客户端目录后，不需要另外发布客户端。

- 桌面端每次连上服务器时读取 `/clients/update` 提供的更新清单。服务器版本高于客户端时，客户端在后台下载对应平台的更新包，校验签名后提示成员重启更新。
- 服务器不再支持当前客户端时，客户端在「需要升级客户端」页面下载新版本，成员确认后重启。
- 更新包由发布流程签名，客户端用内置的公钥校验，签名无效的更新包不会安装。客户端不会更新到低于当前的版本。
- Linux 桌面端不自动更新，成员从下载页手动安装新版本。
