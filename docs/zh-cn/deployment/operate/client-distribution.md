## 下载入口

成员在下载页获取与服务器同版本的桌面端安装包。下载页位于部署地址的 `/zh-cn/download/`（英文为 `/en/download/`），产品首页和文档页头都有入口。Web 应用的「在客户端中使用」，以及客户端版本过低时的升级提示，也会打开这个页面。

服务器从客户端目录读取安装包和更新包，目录由配置项 `clients.directory` 或环境变量 `CLIENTS_DIRECTORY` 指定，默认为 `data/clients`。目录中的 `clients.json` 列出各平台的安装包、更新包及其大小和校验值，这些文件与它放在同一目录下，经 `/clients/<文件名>` 下载。

- 容器镜像内置同版本的桌面端安装包和更新包，客户端目录为 `/clients`，不需要额外配置。
- 使用二进制部署时，把 Release 中的 `clients.json` 和它列出的文件放进客户端目录。
- 服务端启动时读取客户端目录。`clients.json` 的版本与服务端版本不同，或目录中没有 `clients.json` 时，下载页显示当前服务器未提供安装包；列出的文件缺失，或大小、校验值与记录不符时，服务端无法启动。
- 移动端暂未提供下载，下载页显示即将推出。

## 桌面端更新

桌面端从所连接的服务器更新，服务器升级后，成员的桌面端随之更新到同一版本。

- 桌面端启动后检查一次，之后每 6 小时检查一次；成员也可以在用户菜单中选择「检查更新」。发现新版本时先提示成员，确认后才下载。
- macOS 与 Windows 在应用内下载、验证并安装更新，完成后自动重启。当前用户无权写入应用所在目录（如安装在系统的应用程序目录且没有管理员权限）时，以及在 Linux 上，提示新版本后打开下载页，由成员下载安装包自行安装。
- 更新包由发布流程签名，桌面端用构建时内置的公钥验证，签名无效时拒绝安装。
- 客户端目录中没有 `clients.json`，或其版本与服务端不同时，桌面端不提示更新。
