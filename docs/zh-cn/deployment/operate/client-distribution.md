向成员提供桌面端安装和更新；移动端安装包暂未随发布提供。

## 下载入口

成员在下载页获取与服务器同版本的桌面端安装包，管理员在同一页面的「共享电脑执行器」一节下载无界面执行器。下载页位于访问地址的 `/zh-cn/download/`（英文为 `/en/download/`），产品首页和文档页头都有入口。Web 应用的「在客户端中使用」，以及客户端版本过低时的升级提示，也会打开这个页面。

每个 Release 带有发布清单 `release.json`，列出该版本各平台的服务端压缩包、桌面端安装包、更新包和执行器压缩包及其大小和校验值。服务器按程序所在目录中的发布清单，从同一目录的 `clients` 子目录读取客户端文件，经 `/clients/<文件名>` 下载。

- 容器镜像内置同版本的发布清单与客户端文件，不需要额外配置。
- 直接运行程序时，用 `{{slug}}-server download-clients` 从 Release 下载与程序同版本的发布清单与客户端文件，校验大小和校验值后放进程序所在目录；服务器不能访问 Release 时用 `--from` 指定事先下载好的目录，见[独立程序](/docs/zh-cn/deployment/install/standalone/#下载客户端文件)。
- 服务端启动时读取发布清单。没有发布清单，或清单版本与服务端版本不同时，下载页显示当前服务器未提供安装包与执行器，桌面端也不会从这台服务器更新；清单无效、列出的文件缺失，或大小、校验值与记录不符时，服务端无法启动。
- 桌面发布包提供 Windows amd64、macOS arm64、Linux amd64 与 Linux arm64。移动端暂未提供下载，下载页显示即将推出。

## 桌面端更新

Windows 和 macOS 桌面端从所连接的服务器更新，客户端版本始终跟随服务器版本。升级服务器后不需要另外发布客户端。

- 桌面端每次连上服务器时读取 `/clients/update` 提供的更新清单。服务器版本高于客户端时，客户端在后台下载对应平台的更新包，校验 SHA-512 校验值后提示成员重启更新。更新包不使用额外的更新签名，只信任当前连接的服务器提供的清单与摘要。
- 服务器不再支持当前客户端时，客户端在「需要升级客户端」页面下载新版本，成员确认后重启；不能在应用内替换时（见下方 Linux 与目录权限的说明），页面改为打开下载页。
- 内容与更新清单记录的校验值不符的更新包不会安装。客户端不会更新到低于当前的版本。
- Linux 桌面端，以及当前用户无权写入应用所在目录（如没有管理员权限、应用装在系统应用目录）的 Windows 和 macOS 桌面端，不在应用内替换：发现新版本时提示成员 **前往下载**，从下载页手动安装。

## 移动端

移动端应用与官方推送中继尚未随当前发布提供；成员请使用 Web 或桌面端。后续提供时下载页与文档会同步更新。

## 代码签名

macOS 桌面应用与无界面执行器使用 Developer ID 签名并提交 Apple 公证。DMG 和自动更新 ZIP 内的应用附带公证票据；命令行执行器不支持附加票据。Windows 安装包按发布流程使用代码签名证书签名。上述为操作系统要求的应用签名，与桌面更新所用的 SHA-512 摘要校验是两回事。
