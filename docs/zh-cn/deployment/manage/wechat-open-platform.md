---
title: 微信开放平台
order: 9
---

配置部署使用的微信第三方平台、查看平台凭据状态并完成全网发布。只有平台管理员可以打开此页。

> [!NOTE]
> 第三方平台由部署方在[微信开放平台](https://open.weixin.qq.com/)注册并创建，一个第三方平台只用于一个部署。

## 填写平台凭据

在「设置 → 平台 → 部署配置 → 微信开放平台」的「平台凭据」中填写第三方平台「开发资料」里的以下内容，然后保存：

| 字段 | 说明 |
| --- | --- |
| Component AppID | 第三方平台的 AppID，以 `wx` 开头 |
| Component AppSecret | 第三方平台的 AppSecret |
| 消息校验 Token | 3 到 32 位英文字母或数字，可点击「随机生成」 |
| 消息加解密 Key | 43 位英文字母或数字，可点击「随机生成」 |

消息校验 Token 与消息加解密 Key 需要与第三方平台中填写的完全一致。

## 填写接入信息与 IP 白名单

保存平台凭据后，页面显示「接入信息」。把其中的授权发起页域名、授权事件接收 URL 与消息与事件接收 URL 复制到第三方平台的「开发资料」。先在本页保存再填写微信侧配置，微信保存开发资料时推送的验证票据才能被接收。

「IP 白名单」列出每台服务器的出口 IP，把它们全部加入第三方平台的白名单。出口 IP 由各服务器配置中的 [`server.egressIP`](/docs/zh-cn/deployment/configure/configuration/) 填写；显示「未配置出口 IP」时，先在该服务器的配置中补上并重启。

## 查看平台状态

微信每 10 分钟向授权事件接收 URL 推送一次验证票据。收到票据后，服务端自动获取平台凭据，并在凭据到期前用最近的票据续期。

| 状态 | 说明与处理方式 |
| --- | --- |
| 等待微信推送验证票据 | 尚未收到票据。确认授权事件接收 URL、消息校验 Token 与消息加解密 Key 已正确填写，等待下一次推送 |
| 正在获取平台凭据 | 已收到票据，平台凭据尚未获取或已过期，服务端会自动重新获取；也可以点击「重新检测」 |
| 可用 | 平台凭据在有效期内 |
| 获取平台凭据失败 | 按提示处理后点击「重新检测」。提示出口 IP 不在白名单时，把提示中的 IP 加入第三方平台的白名单 |

## 选择权限集与全网发布

在第三方平台的「权限集」中勾选公众号的消息管理、用户管理与素材管理权限。不要勾选小程序相关权限，{{product}}不应答小程序的发布检测。

第三方平台全网发布前，只有「授权测试公众号列表」中的公众号可以授权，可以先把要接入的公众号加入该列表完成测试。

平台状态为「可用」后，在第三方平台提交全网发布。微信用专用测试公众号自动检测，{{product}}自动应答：文本消息检测与事件检测直接回复约定内容，客服消息检测用推送的授权码换取授权后经客服消息接口回复。测试公众号的消息不写入任何会话。

> [!NOTE]
> 公众号授权第三方平台后，公众号后台的服务器配置如果仍然启用，微信会把同一条消息同时推送到两处。同一公众号的[密钥接入](/docs/zh-cn/integrations/channels/wechat-official-account-key/)渠道与授权接入渠道同一时间只能启用一个，启用其中一个前需要先停用另一个。

## 更换第三方平台

修改 Component AppID 并保存，即更换为另一个第三方平台。原平台的验证票据与平台凭据会被清除，需要等待新平台推送验证票据；已授权的[授权接入公众号](/docs/zh-cn/integrations/channels/wechat-official-account-authorization/)渠道需要重新授权。
