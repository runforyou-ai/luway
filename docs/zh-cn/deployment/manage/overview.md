平台管理员查看本平台的使用规模、活跃情况、客服业务使用和模型用量。服务端与后台任务的运行情况见「运行状态」「近期错误」和「日志」页签，说明见[运行状态与诊断](/docs/zh-cn/deployment/manage/diagnostics/)。

## 进入平台管理

平台管理员在任一工作区打开「设置」，左侧导航的「平台」分组包含「概览」「工作区与账号」「部署配置」和「授权」。只有平台管理员能看到这个分组。

## 账号与工作区

「概览」的「平台规模」页签显示：

- 账号总数与近 30 天新增账号数；
- 工作区总数与全部工作区的成员总数；
- 近 7 天与近 30 天的活跃账号数、活跃工作区数；
- 近 30 天每天的活跃账号数，悬停柱子可以看到当天的活跃工作区数和新增账号数；期间没有活跃账号时显示文字提示。

服务器标识、授权状态和工作区上限在「授权」页查看，见 [授权](/docs/zh-cn/deployment/manage/license/)。

工作区总数包含正常和已暂停的工作区。每个工作区的规模、存储用量和最近活跃时间见 [账号与工作区](/docs/zh-cn/deployment/manage/accounts-workspaces/)。

## 业务使用

「概览」的「业务使用」页签按所选统计周期（近 7 天、30 天或 90 天）汇总平台整体和每个工作区的客服数据与模型用量：

| 指标 | 说明 |
| --- | --- |
| 服务周期 | 统计周期内关闭的服务周期数，以及这些周期来自多少个会话 |
| AI 独立解决率 | AI 员工接待过的周期中，由 AI 员工独立处理并解决的比例，同时显示 AI 员工接待过的周期数 |
| 转人工率 | AI 员工接待过的周期中，发生过转人工的比例 |
| 真人首响 | 需要真人后到真人首次回复客户的时长中位数，只计客服工作时间；平台整体另显示 90% 的周期在多长时间内得到回复 |
| 待补知识 | 当前全部待处理的待补知识条数，不受统计周期限制 |
| 模型调用 | 统计周期内开始的模型调用次数和失败率 |
| 模型 Token | 模型调用消耗的输入与输出 Token，输入中另显示命中缓存的部分 |

AI 独立解决率、转人工率、真人首响和待补知识与工作区内「AI 表现」「团队表现」报表的口径一致，工作区管理员在未加筛选的报表里看到的是同样的数字。工作区列表可以按服务周期、会话、真人首响、待补知识或模型 Token 排序。

## AI 与资源

「业务使用」统计工作区自配模型与共享模型的调用和 Token。

- 失败率 =（失败 + 超时）÷ 已结束的调用。已结束的调用指成功、失败和超时的调用，进行中和已取消的调用不计入分母。
- 一次调用尝试了多个来源时只计一次，结果以最终状态为准。
- 模型 Token 是输入与输出 Token 之和，命中缓存的输入 Token 包含在输入中。

每个工作区占用的存储空间见 [账号与工作区](/docs/zh-cn/deployment/manage/accounts-workspaces/)。

## 统计口径

- 活跃账号：当天发过消息，或处理过客服会话（回复、接手、关闭、转派）的账号。同一账号加入多个工作区时，平台级账号数只计一次。
- 活跃工作区：当天有活跃成员，或有客户消息、AI 员工回复的工作区。
- 活跃与新增按「平台时区」划分日期。平台时区在「部署配置」的「基本信息」中修改，见[平台时区](/docs/zh-cn/deployment/configure/address/#平台时区)，修改后按新时区重新统计全部历史数据，完成前页面显示「正在按新时区重新统计」。
- 活跃数据每 10 分钟汇总一次，最近的操作可能稍后才计入。
- 业务使用按服务周期的结束时间、模型调用的开始时间统计最近若干天，统计范围是正常和已暂停的工作区。
- 运营数据只包含计数、时长和状态，不包含消息正文、客户资料和凭据。
