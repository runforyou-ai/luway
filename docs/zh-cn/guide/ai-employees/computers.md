## 电脑类型

- 个人电脑：成员自己的电脑，只为这位成员的个人 AI 员工执行操作，成员停用后不再可用。
- 工作区电脑：属于工作区的电脑，为选择使用它的服务型 AI 员工执行操作，不随成员停用而失效。

## 注册电脑

在电脑上安装并登录桌面端后，这台电脑自动注册为你在各个工作区的个人电脑，出现在「设置 › 电脑」中；撤销后重新登录桌面端会再次注册。

工作区电脑在「AI 员工 › 工作区电脑」中添加，用连接信息启动无界面执行器，详见[工作区电脑](/docs/zh-cn/integrations/computers/#注册工作区电脑)。

## 共享文件区副本

每个会话在电脑上有自己的默认文件夹，其中的 `shared/` 是这个会话[共享文件区](/docs/zh-cn/guide/daily/chats/#会话共享文件)的副本，路径与 AI 员工文件工具中的 `shared/` 一致。运行命令和本机 Agent 的每一轮在执行前后各同步一次：

- 共享文件区中新增或修改的文件取到电脑上；成员删除的文件，电脑上未改动时一并删除。
- 电脑上新建或修改的文件写回共享文件区，修改人记为这名 AI 员工；命令的结果中会列出写回的文件。
- 文件在电脑上次同步后已在共享文件区被改动或删除时，电脑上的版本另存为「名称（电脑上的版本）」，原文件取共享文件区的内容，已被删除时电脑上也不再保留。
- 电脑上删除的文件不会删除共享文件区中的文件，下次同步时取回。

本机 MCP、浏览器与桌面操作不同步。

## 本机 Agent

本机 Agent 是电脑上经 ACP 协议接入的 Agent，例如 Codex、Claude Code。AI 员工可以把编程、整理文件等需要连续操作的任务交给它完成，用户始终与 AI 员工对话。

- 可用的本机 Agent：电脑上已安装 `codex` 或 `claude` 命令行工具且可以使用 `npx` 时，自动提供对应的 Codex 或 Claude Code；其他 Agent 写入数据目录中的 `agents.json`，格式为 `{"agents": {"名称": {"description": "用途说明", "command": "启动命令", "args": [], "env": {}}}}`，修改后重启桌面端或执行器生效。
- 启用：在 AI 员工资料的「本机 Agent」中勾选。个人 AI 员工可以使用自己电脑上的本机 Agent，服务型 AI 员工使用工作区电脑上的本机 Agent。服务客户时不使用本机 Agent。
- 交给本机 Agent：AI 员工把你的原话交给它，并附上此前讨论的结论、提到的文件与报错等补充信息；本机 Agent 看不到完整的会话记录和 AI 员工的记忆。
- 过程与回复：AI 员工的回复下方出现本机 Agent 的卡片，实时显示它的回复、思考、执行步骤、文件改动与任务清单；完成后本机 Agent 的最终回复原样发到会话中，并标明来自哪个本机 Agent。
- 追问：在同一会话中继续交给同一个本机 Agent 时续接原来的会话，它记得此前各轮；要求重新开始时开启新会话。支持恢复会话的本机 Agent 空闲 30 分钟后进程关闭，再次交给它时重新启动并恢复原来的会话。
- 权限：本机 Agent 执行需要授权的步骤前，会话中出现确认卡片，由这一轮的发起人允许或拒绝，24 小时内未处理时请求取消。
- 停止：在卡片上停止，正在执行的一轮中断，排队的轮次取消；之后再交给它时开启新会话。

本机 Agent 使用电脑上自己登录的账号调用模型。需要登录时，会话中会提示先在电脑上登录。
