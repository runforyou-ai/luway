工作区使用[平台模型](/docs/zh-cn/guide/workspace/models/#平台模型)时，按模型的价格从工作区的积分中扣除。工作区自己配置的模型不扣积分。入口在「设置 → 集成 → 积分」。

## 余额与每日赠送

积分页上方显示两项：

- 可用积分：工作区现在可以使用的全部积分。
- 今日赠送剩余：今天的每日赠送还剩多少，以及什么时候清零。

平台管理员开启每日赠送后，每个工作区每天自动获得同样数量的积分。当天没用完的部分在当天结束时清零，不会累积到第二天。平台管理员手动增加的积分和充值的积分不会过期。

使用积分时先扣即将清零的每日赠送，再扣不会过期的积分。

## 扣费方式

平台模型的价格由平台管理员设置，选择模型时显示在模型名称后，例如「输入 2 · 输出 8 积分/百万 Token」：

- 对话模型按输入和输出的 Token 数计价；
- 向量化和重排序模型按输入的 Token 数计价；
- 判断模型按调用次数计价；
- 有的模型另外按每次调用计价，价格为 0 的模型免费。

每次调用开始前，会按输入长度和模型的最大输出先预占一部分积分，调用结束后按实际用量多退少补。调用失败且没有产生用量时，预占的积分全部退回。实际费用超过预占而余额不够补扣时，最多扣到余额为 0，不会产生欠款。

## 积分流水

积分页下方按时间倒序列出积分的变动：

| 记录 | 说明 |
| --- | --- |
| 每日赠送 | 当天赠送的积分 |
| 平台调整 | 平台管理员手动增加或扣减，带调整备注 |
| 模型调用 | 一次调用一条，显示模型、用途、Token 用量和扣除的积分；调用进行中时标记「预占中」 |
| 充值 | 工作区购买并支付成功的积分 |
| 充值退款 | 充值订单退款时扣回这笔充值尚未使用的积分，已使用的部分不追回 |
| 积分过期 | 已作废的积分，如当天没用完、已清零的赠送积分 |

## 积分不足

可用积分不足以支付一次调用的预占时，这次调用不会执行：AI 员工无法回复，翻译、小结、知识库检索等使用平台模型的功能暂停，成员发起的操作会提示「工作区积分不足」。工作区自己配置的模型不受影响。

等第二天的每日赠送发放，或联系平台管理员增加积分后即可恢复。也可以在用到模型的设置里改用工作区自己配置的模型，见[模型服务](/docs/zh-cn/guide/workspace/models/)。
