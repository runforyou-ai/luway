---
title: 角色与权限
order: 3
---

按角色控制成员可以使用的功能。入口在「设置 → 工作区 → 角色与权限」。

每位成员在工作区中属于一个角色，角色授予的权限决定成员可以管理哪些功能。调整角色的权限或成员所属的角色后立即生效，导航和设置中只显示成员有权限使用的入口。

## 内置角色

每个工作区自带三个内置角色：

| 角色 | 默认权限 |
| --- | --- |
| 管理员 | 全部权限，不能修改 |
| 客服 | 外部联系人管理 |
| 成员 | 无 |

创建工作区的成员属于「管理员」。「客服」与「成员」的权限可以调整，名称不能修改，也不能删除。工作区中至少要保留一位状态正常的管理员。

## 自定义角色

在「角色与权限」页点击新建，填写角色名称与说明并勾选权限。自定义角色可以随时修改或删除，删除前需要先把其中的成员调整到其他角色。每个工作区最多 20 个角色。

## 管理员

拥有「工作区管理」权限的成员可以新建、修改和删除角色，并把成员调整到除「管理员」以外的任何角色。涉及管理员的操作只有管理员可以做：分配「管理员」角色、邀请管理员、重新生成或撤销管理员的邀请，以及编辑、停用或恢复管理员。

## 权限说明

| 权限 | 可以使用的功能 |
| --- | --- |
| 工作区管理 | 通用设置；邀请、编辑、停用与恢复成员，管理团队；角色与权限；模型服务、联网搜索与业务系统；工作区电脑；启停他人负责的个人 AI 助手 |
| AI 员工管理 | 新建、编辑、停用与启用 AI 员工，维护评测，查看服务记录；知识库中的文档与问答；处理任意 AI 员工的待补知识 |
| 客服管理 | 渠道；营业时间、超时、会话小结、翻译、客户身份密钥、服务分类、联系人字段与标签 |
| 外部联系人管理 | 新建、编辑、删除与恢复外部联系人，填写联系人字段与标签 |
| 数据报表 | AI 表现与团队表现报表 |

拥有某项权限即可进入对应页面并修改，没有权限时不显示入口。以下功能不受角色权限限制，所有成员都可以使用：

- 消息、私聊、群聊与收件箱中的会话处理。
- 通讯录中的同事、团队与外部联系人，个人 AI 助手、个人资料与偏好、自己的电脑。
- 查看待补知识，处理本人负责的 AI 员工的待补知识。
