工作区使用平台模型时按价格扣除工作区的积分。平台管理员设置每日赠送，也可以为单个工作区手动增加或扣减积分。平台模型的价格见[平台模型服务](/docs/zh-cn/guide/admin/platform-models/#价格)。

## 每日赠送

在「设置 → 平台 → 积分」中填写「每日赠送积分」，每个工作区每天自动获得这么多积分，填 0 表示不赠送。

- 赠送在工作区当天第一次使用或查看积分时发放，同一天只发一次。
- 「一天」按平台时区划分，平台时区在[平台概览](/docs/zh-cn/guide/admin/overview/)中修改。当天没用完的赠送在平台时区当天结束时清零。
- 修改赠送积分或平台时区，从下一次赠送起生效，已经发放的赠送不变。

## 查看与调整工作区积分

在「全部工作区」中点击工作区，或在行操作中选择「积分」，打开工作区的积分侧栏，可以看到可用积分、今日赠送剩余和积分流水。

点击「调整积分」，选择增加或扣减，填写积分和备注：

- 增加的积分不会过期。
- 扣减时先扣即将清零的赠送积分，最多扣到余额为 0。余额不足时按实际扣减的积分提示。
- 备注会显示在工作区的积分流水中，工作区成员可以看到。

## 计费规则

- 每次调用开始前按输入长度和模型的最大输出预占积分，可用积分不足时这次调用不执行，成员会看到「工作区积分不足」。
- 调用结束后按实际用量多退少补。实际费用超过预占且余额不够补扣时，最多扣到余额为 0，少扣的部分记在调用记录中，余额不会变成负数。
- 调用失败且没有产生用量时，预占全部退回。
- 工作区充值的积分不会过期；充值订单退款时扣回这笔充值尚未使用的积分，已使用的部分不追回。
- 一次调用尝试了多个来源时，所有来源产生的用量都计费。

「模型调用」中的每条记录都显示扣除的积分，工作区看到的说明见[积分](/docs/zh-cn/guide/workspace/credits/)。
