查看平台运行状态，导出或上报诊断信息。

## 运行状态

平台管理员在「设置 → 平台 → 运行状态」查看：

- 在线的服务器数，以及它们运行的版本；
- 已到执行时间仍在排队的后台任务数，以及等待最久的任务已经等了多久；
- 执行中的任务数，以及因工作区暂停而挂起的任务数；
- 近 7 天失败且不再重试的任务数，以及执行失败后等待重试的任务数。

「任务队列」按队列列出排队、执行中、重试中、挂起和失败的任务数。等待数持续增长或等待时间很长时，说明处理该队列的服务器不足或执行受阻。页面每 15 秒自动刷新。

## 服务器

「服务器」列出正在运行的每个服务端进程，显示主机名、版本、实例编号、启动时间和最近一次心跳。服务端每 30 秒发送一次心跳：

- 超过 2 分钟没有心跳的服务器标为「失联」，通常是进程意外退出或无法连接数据库。失联超过 1 小时的记录会被自动删除，正常停止的服务器会立即从列表中消失。
- 服务端执行后台任务和推送实时消息各用一条 NATS 连接。后台任务的连接断开时标为「后台任务未连接 NATS」，这台服务器暂时不领取后台任务；实时通知的连接断开时标为「实时通知未连接 NATS」，连接到这台服务器的成员暂时收不到实时更新；两条都断开时标为「NATS 未连接」。
- 页面顶部显示在线服务器运行的版本，滚动升级期间可能同时运行多个版本；有失联或 NATS 连接异常的服务器时也会一并显示数量。

## 外部依赖

「外部依赖」显示服务端依赖的外部服务：

| 依赖 | 状态 |
| --- | --- |
| 对象存储 | 未开启对象存储时显示「未开启」，文件保存在服务器本地目录。开启时每次刷新页面，服务端都会用配置的凭据访问一次存储桶，访问失败时显示「检查失败」和错误信息。这项检查需要凭据有访问存储桶本身的权限，凭据只能读写文件时也会显示检查失败 |
| 授权服务 | 显示最近一次同步成功的时间。授权服务中没有授权，或只有已到期的授权时，同步也算成功。连接失败、授权码验证或保存失败时显示失败时间和原因，此后同步成功或在线激活成功会恢复正常 |

点击状态异常的依赖可以在侧栏查看完整的错误信息。服务端每天与授权服务同步一次，也可以在授权页手动同步。

## 近期错误

「近期错误」分为两个页签。

「重试中与失败的任务」列出全部等待重试的任务和近 7 天失败的任务，按最近一次执行失败的时间倒序排列。每条显示任务名称、所属工作区（平台级任务显示为「平台级任务」）、最后一次错误信息、执行次数和失败时间，点击任务可以在侧栏查看完整的错误信息。

「服务端错误」列出近 7 天所有服务器记录的错误，按发生时间倒序排列，包括处理请求失败、发生异常和后台任务最后一次重试仍失败。每条显示出错的操作或任务名称、错误说明、服务器主机名、错误信息的第一行和发生时间。点击错误可以在侧栏查看主机、服务器实例、版本、事件编号、其他记录信息和完整的错误信息。开启上报时，事件编号与上报给授权服务的错误事件一一对应。

已结束的任务记录和服务端错误保留 7 天，之后自动清理。服务器无法连接数据库时，错误不会出现在这里，只写入服务端本地日志。

## 诊断导出

需要运维人员或技术支持协助排查时，平台管理员在「运行状态」页头点击「导出诊断信息」，生成一个 JSON 文件。Web 端直接下载，桌面端选择保存位置。文件名是 `diagnostics-` 加导出时间。

文件包含：

| 内容 | 说明 |
| --- | --- |
| 基本信息 | 生成时间、执行导出的服务器实例编号 |
| 平台概览 | 服务器标识、统计时区、账号数、工作区数、成员数，近 7 天、近 30 天的活跃和新增情况，近 30 天的逐日趋势，以及授权状态 |
| 服务器 | 每台服务器的版本、启动时间、最近心跳、NATS 连接状态，以及启动时的配置 |
| 外部依赖 | 对象存储检查结果和授权服务同步结果。对象存储由执行导出的服务器检查 |
| 数据库 | PostgreSQL 版本和已执行的最新迁移版本 |
| 后台任务 | 各队列的任务数，全部等待重试和近 7 天失败的任务，以及完整的错误信息 |
| 模型供应商 | 平台供应商近 24 小时的尝试次数、失败次数和最近一次错误 |

服务器配置只包含部署地址、监听地址、TLS 模式、数据库和 NATS 的地址、存储方式与存储桶、邮件服务器地址等。数据库密码、对象存储密钥、SMTP 账号和密码不会写入文件，地址中的账号和密码也会去掉。后台任务只写所属工作区的编号，不写工作区名称。文件不包含消息、客户资料等业务内容，也不包含服务端日志，日志的查看方式见[监控与诊断](/docs/zh-cn/deployment/operate/monitoring/)。

## 上报配置

「平台概览」页的「上报运行指标与错误」开关控制本平台是否向授权服务上报运行数据，默认开启。修改后当前服务端实例立即生效，其他实例在一分钟内生效。

开启时上报以下内容：

- 运行指标：每分钟上报账号数、工作区数、成员数，以及近 7 天的活跃账号数和活跃工作区数；
- 错误：服务端处理请求失败、发生异常，或后台任务最后一次重试仍失败时，上报出错的操作或任务名称、错误类型、数据库错误码、发生异常时的调用栈、服务端版本和运行环境。

错误信息原文不上报，只保存在本平台：可以在「近期错误」的「服务端错误」中查看，服务器无法连接数据库时只写入服务端本地日志。「服务端错误」侧栏中的事件编号和本地日志中的 `event_id` 与上报的错误事件一一对应，排查时可以据此找到完整的错误信息。上报内容不包含消息正文、客户资料、文件内容、访问令牌、密码、密钥和服务器主机名。

关闭上报后，服务端仍会每天与授权服务同步一次授权。
