## 更新与版本兼容

Web 端随服务器一起更新，不需要单独升级。桌面端和移动端需要与服务器版本匹配：

- Windows 和 macOS 桌面端每次连上服务器时，从服务器下载与它同版本的新客户端，下载完成后提示 **重启并更新**，重启后即为新版本。
- 服务器升级后不再支持当前客户端时，客户端进入「需要升级客户端」页面。Windows 和 macOS 桌面端自动下载新版本，下载完成后点击 **重启并更新**；Linux 桌面端和移动端点击 **下载新版本** 打开当前服务器的下载页，安装新版本后重新打开。也可以点击 **更换服务器** 连接其他服务器。
- 服务器版本低于客户端的要求时，客户端在连接页提示服务器版本过旧，请联系管理员升级服务器。
