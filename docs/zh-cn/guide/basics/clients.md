## 下载与安装

## 连接服务器

桌面端和移动端使用完整服务器地址连接，包括 `https://` 或 `http://` 前缀。检测成功后，确认区显示目标服务器的产品名称，点击 **连接** 进入登录页。登录页底部显示当前服务器的产品名称，可点击 **更换服务器** 返回连接页；桌面端悬停在连接确认区或登录页的产品名称上可查看完整地址。

## 在客户端中使用

桌面端工作台顶部提供侧栏开关、后退和前进按钮，收起侧栏后仍保留这些操作。拖动顶部空白区域可以移动窗口。macOS 的窗口按钮位于左侧；Windows 和 Linux 的最小化、最大化或还原、关闭按钮位于右侧。登录与连接服务器的小窗口保持固定尺寸。

Windows 窗口顶栏提供 **文件、编辑、显示、窗口** 菜单，可关闭窗口、退出应用、编辑文本、调整页面缩放和切换全屏。按 `F10` 聚焦菜单，或用 `Alt+F/E/V/W` 打开对应菜单，再用方向键、回车和 Esc 操作。关闭主窗口会隐藏到托盘，**文件 → 退出** 会结束应用。macOS 使用屏幕顶部的系统菜单栏。

## 更新与版本兼容

Web 端随服务器一起更新，不需要单独升级。桌面端和移动端需要与服务器版本匹配：

- Windows 和 macOS 桌面端每次连上服务器时，从服务器下载与它同版本的新客户端，下载完成后提示 **重启并更新**，重启后即为新版本。Linux 桌面端，或当前账户无权写入应用所在目录时，提示有新版本，点击 **前往下载** 从下载页手动安装。
- 服务器升级后不再支持当前客户端时，客户端进入「需要升级客户端」页面。Windows 和 macOS 桌面端自动下载新版本，下载完成后点击 **重启并更新**；Linux 桌面端、移动端，以及当前账户无权写入应用所在目录时，点击 **下载新版本** 打开当前服务器的下载页，安装新版本后重新打开。也可以点击 **更换服务器** 连接其他服务器。
- 服务器版本低于客户端的要求时，客户端在连接页提示服务器版本过旧，请联系管理员升级服务器。
