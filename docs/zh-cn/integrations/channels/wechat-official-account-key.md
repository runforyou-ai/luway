用公众号自己的 AppID 与 AppSecret 接入已认证的服务号并接待客户。部署配置了微信开放平台时，也可以改用[授权接入](/docs/zh-cn/integrations/channels/wechat-official-account-authorization/)，由公众号管理员扫码授权，无需填写公众号凭据。

## 准备工作

- 已认证的服务号，以及能登录微信公众平台「设置与开发 › 基本配置」的管理员。
- 部署方已在每台服务器的服务端配置中填写出口 IP（`server.egressIP`），见[配置参考](/docs/zh-cn/deployment/configure/configuration/)。
- 一个公众号在同一部署中只能连接到一个密钥接入渠道；渠道连接公众号后不能更换 AppID，更换公众号请新建渠道。

## 连接公众号

在渠道的「连接」页签填写公众号凭据：

| 字段 | 取值 |
| --- | --- |
| AppID、AppSecret | 公众平台「设置与开发 › 基本配置」中的开发者 ID 与开发者密码 |
| 令牌（Token） | 3 到 32 位英文字母或数字，可随机生成 |
| 消息加解密方式 | 安全模式或明文模式，推荐安全模式 |
| 消息加解密密钥（EncodingAESKey） | 安全模式下填写 43 位英文字母或数字，可随机生成 |

保存前，先把「连接」页签「IP 白名单」中列出的全部服务器出口 IP 加入公众平台「设置与开发 › 基本配置」中的 IP 白名单。保存时{{product}}用 AppID 与 AppSecret 向微信获取接口调用凭据，验证通过后才保存；出口 IP 不在白名单时提示对应的 IP。

## 连接状态

| 项目 | 含义 |
| --- | --- |
| 接口凭据 | 「可用」表示最近一次获取凭据成功，凭据即将到期时在下次调用微信接口前自动重新获取；「获取失败」时显示原因，例如出口 IP 不在白名单或微信拒绝了凭据，处理后点击「重新检测」 |

## 服务器配置

连接公众号后，「连接」页签显示「服务器配置」。在公众平台「设置与开发 › 基本配置 › 服务器配置」中：

1. 服务器地址（URL）填写「服务器配置」中的地址，可点击「复制」。
2. 令牌（Token）、消息加解密方式与消息加解密密钥（EncodingAESKey）填写与渠道凭据相同的值。
3. 提交后微信验证服务器地址，验证通过时「地址验证」显示「已验证」与验证时间。
4. 启用服务器配置。

修改渠道的令牌（Token）后「地址验证」恢复为「等待验证」，在公众平台改为同样的令牌并重新提交。

> [!NOTE]
> 启用服务器配置后，公众号收到的消息由{{product}}处理，公众平台中设置的自动回复和自定义菜单停止生效。同一公众号的授权接入渠道启用时，本渠道不能启用。

## 接收消息

渠道启用时，客户发给公众号的消息写入该客户的会话，并按渠道的接待设置分配处理人。

| 客户发送的消息 | 写入会话的内容 |
| --- | --- |
| 文字 | 文字消息 |
| 图片、语音、视频、小视频 | 附件；语音保存为微信提供的原始音频文件 |
| 位置 | 文字，包含位置名称与经纬度 |
| 链接 | 文字，包含标题、描述与网址 |

关注、扫码与菜单点击不写入会话，只开启回复窗口，见[消息回复](#消息回复)。微信不向公众号提供用户的昵称与头像，客户在联系人中以编号显示。同一公众号的密钥接入与授权接入渠道同一时间只能启用一个；在两种接入方式之间切换后，同一位客户仍对应同一个联系人。

## 消息回复

处理人和 AI 员工在会话中的回复经公众号客服消息发送给客户。微信只允许在客户与公众号互动后的一段时间内回复：

| 客户的互动 | 可回复时长 | 可回复条数 |
| --- | --- | --- |
| 发送消息 | 48 小时 | 5 条 |
| 关注公众号、扫描带参数二维码、点击菜单 | 1 分钟 | 3 条 |

会话输入区显示可回复的截止时间与剩余条数。超过时长或条数用完后不能发送，客户再次发消息或互动后恢复。

- 文字：每条最多 2048 字节，约 680 个汉字。AI 员工超过上限的回复拆成多条发送，每条计入可回复条数；剩余条数不够发完全部段落时，整条回复不发送。
- 图片：JPG、PNG、GIF，10MB 以内。
- 语音：AMR、MP3，2MB 以内。
- 附件不带说明文字，不能引用消息，也不能发送其他类型的文件。
