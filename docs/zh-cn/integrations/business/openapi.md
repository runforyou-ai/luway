业务系统可以按 OpenAPI 文档提供 HTTP 接口，每个接口生成一个工具。

## OpenAPI 文档

支持 OpenAPI 3.x 的 JSON 或 YAML 文档，不支持 Swagger 2.0。文档可以填写文档地址，也可以直接粘贴：

- **文档地址**：保存与更新工具时从该地址读取文档，读取文档时不附带凭据。文档需要认证才能访问时，改用粘贴文档。
- **粘贴文档**：文档保存在业务系统中，接口变化后需要重新粘贴。

文档中的引用只展开文档内部的 `#/...` 引用。请求体只支持 JSON 媒体类型（`application/json` 或以 `+json` 结尾的类型），调用时按文档声明的类型提交；请求体不是 JSON 的接口不生成工具。

## 接口根地址

工具按接口根地址加接口路径调用。接口根地址留空时使用文档 `servers` 中的第一个地址，相对地址按文档地址解析；文档没有可用的地址时须填写接口根地址。

## 工具与参数

工具名称取接口的 `operationId`，没有时或与已有工具重名时取「方法 路径」，例如 `GET /orders/{id}`，仍重名时追加序号。工具说明取接口的 `summary` 与 `description`。

工具的参数由接口的路径、查询与请求头参数和请求体组成：请求体是对象时，可写的字段逐个作为参数；请求体不是对象或字段与其他参数同名时，整个请求体作为 `body` 参数。参数绑定可以把路径、查询、请求头参数或请求体字段绑定到身份，见 [业务系统](/docs/zh-cn/integrations/business/connectors/)。

查询参数按文档声明的 `style` 与 `explode` 序列化，路径与请求头中的数组以逗号连接。请求体字段给出 `null` 时原样提交，用于清空字段。

## 默认性质

`GET` 与 `HEAD` 接口默认只读，其他方法的接口默认是不可撤销的写操作，即 L3。可以在工具设置中修正，例如把创建工单的 `POST` 接口改为可撤销。

## 调用结果

响应正文不能超过 8 MB。返回 2xx 状态码时，响应正文原样交给 AI 员工，没有正文时只给出状态码。其他状态码视为调用失败，状态码与响应正文作为失败原因交给 AI 员工。接口返回的重定向不会被跟随。
